## 4. Project Workflow

The project follows these steps:

**Step 1: Data Loading**
- Imported the dataset into Python using Pandas.
- Examined the dataset structure, columns, and data types.

**Step 2: Exploratory Data Analysis (EDA)**
- Analyzed data distributions and patterns.
- Identified trends, relationships, and outliers.
- Generated visualizations to understand the dataset.

**Step 3: Data Cleaning**
- Handled missing and duplicate values.
- Corrected data types and inconsistent entries.
- Prepared the dataset for further analysis.

**Step 4: SQL Analysis**
- Imported cleaned data into a SQL database.
- Performed queries using SELECT, WHERE, GROUP BY, ORDER BY, and JOIN.
- Used aggregate functions and subqueries to answer business questions.
- Extracted meaningful insights from the data.

**Step 5: Power BI Dashboard**
- Connected the cleaned dataset to Power BI.
- Created KPIs, charts, graphs, and interactive filters.
- Designed a dashboard to communicate key findings.

**Step 6: Report Creation**
- Documented the analysis process.
- Summarized key findings and business insights.
- Presented results in a structured report.

**Step 7: Presentation**
- Created a professional project presentation using Gamma.
- Highlighted the project objective, methodology, dashboard, and key findings.
